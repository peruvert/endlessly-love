# The Things I Keep

A playful editorial scrapbook made by Khaleed for Yon. Each chapter has its own layout and color identity, with shared navigation and a warm, magazine-like feel.

## Open locally
1. Extract the ZIP.
2. Open the `the-things-i-keep` folder in VS Code.
3. Open `index.html` with Live Server.

## Live site
Published at https://peruvert.github.io/endlessly-love/

## Pages
- `index.html` — A Little Something, the cover
- `subject.html` — The Things I Notice
- `collection.html` — In Passing, a photo essay
- `letter.html` — A Few Words
- `soundtrack.html` — On Repeat
- `gift.html` — Something for You, an interactive gift
- `last.html` — Until Then, a quiet closing note

## Replace photographs
Place image files in `assets/images/` and keep these filenames:
- `hero.jpg`
- `juione-01.jpg`
- `khaleed-01.jpg`
- `moment-01.jpg`
- `moment-02.jpg`

The pages automatically use the local image when the matching file exists. Otherwise, a styled placeholder remains. Camera Roll photos open in a fullscreen viewer, including when a replacement photo is not present. No database or upload form is used.

## Fonts and palette
- DM Sans — main interface and body text
- Libre Baskerville — editorial headlines and selected copy
- Oswald — selected display labels
- DM Mono — labels, numbering and navigation
- Colors: antique ivory, warm stone, Parisian blue, slate navy, oxblood, deep wine and espresso, with restrained antique brass accents

## Playlist audio
The first five tracks are stored in `assets/audio/`. Add future tracks there and update the playlist in `soundtrack.html`.
